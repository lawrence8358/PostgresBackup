# 04: 備份歷史倉儲與稽核管理

**What to build:** 抽離 `IBackupHistoryRepository` 隔離 SQLite 資料庫。每當備份作業完成時，系統自動將備份紀錄（時間戳記、資料庫名稱、檔案路徑、格式、檔案大小、耗時、狀態與執行參數）寫入歷史倉儲。在 WPF 介面中提供歷史紀錄清單，支援時間與狀態篩選、開啟檔案所在目錄，並可選取特定歷史檔案發起還原。
