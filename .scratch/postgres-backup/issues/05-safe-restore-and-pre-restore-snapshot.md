# 05: 安全防護還原作業與還原前安全快照

**What to build:** 提供具備安全防護機制的還原作業。在對目標資料庫執行 `pg_restore` 或 `psql` 之前，系統預設且強制發起「還原前安全快照」，在確認快照成功後才允許繼續執行還原。還原前跳出高危險性警示對話框，需使用者確認目標資料庫。支援多種還原模式（清除並重建、僅建立、僅資料）。CLI 支援 `restore` 指令並支援 `--no-snapshot` 等進階旗標；WPF 提供步進式還原精靈與進度追蹤。還原完成後自動寫入歷史稽核紀錄。

**Blocked by:** 04: 備份歷史倉儲與稽核管理

**Status:** done

- [x] 還原作業執行前自動調用 `pg_dump` 建立目標資料庫的安全快照檔案
- [x] 若安全快照失敗，立即中止還原作業以確保資料庫安全
- [x] 提供危險操作二次確認機制，明確警示受影響之資料庫
- [x] 支援 Custom 二進位檔（`pg_restore`）與 Plain SQL 腳本（`psql`）的還原
