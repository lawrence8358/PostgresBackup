# 03: 備份作業核心與即時日誌流

**What to build:** 提供完整的備份作業能力。使用者可選擇完整資料庫備份、指定綱要（Schema）或指定資料表備份；支援自訂二進位（Custom）或純文字腳本（Plain SQL）格式；可切換僅結構、僅資料或結構與資料。CLI 提供 `backup` 命令並支援 `--log` 輸出日誌；WPF 提供現代化備份設定面板與即時命令輸出終端視窗。備份檔案遵循 `{database}_{yyyyMMddHHmmss}` 自動規範命名。
