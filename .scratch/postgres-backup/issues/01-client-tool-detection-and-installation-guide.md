# 01: 客戶端工具偵測管線與官方安裝指引

**What to build:** 系統在啟動時或依使用者要求自動掃描本機環境中 PostgreSQL 官方 `pg_dump` 與 `pg_restore` 工具。在 CLI 中提供環境檢查指令並輸出版本診斷資訊；在 WPF 中以清晰狀態燈號（就緒、版本不相容、未偵測到）呈現，並於未找到或版本過低時提供內建之官方安裝指引面板（含官方下載連結及 Winget 快速安裝指令）。同時允許使用者自訂工具路徑。

**Blocked by:** None (can start immediately)

**Status:** done

- [x] 能自動掃描自訂路徑、環境變數 PATH、常見安裝路徑與 Registry 並解析工具版本
- [x] 支援與 PostgreSQL 伺服器主版本進行相容性比對，低於伺服器版本時明確標記警示
- [x] CLI 提供檢查指令並印出詳細診斷資訊
- [x] WPF 介面即時顯示工具狀態指示燈，並具備官方安裝指引面板
- [x] 允許使用者手動瀏覽或輸入客戶端工具目錄並即時重新驗證
- [x] 撰寫外部行為單元測試，驗證多種路徑環境與版本判定邏輯
