# 02: PostgreSQL 連線管理與憑證安全存儲

**What to build:** 使用者可配置並保存多組 PostgreSQL 連線設定（主機、通訊埠、資料庫、帳號、密碼）。提供連線測試功能以即時驗證網路連線與憑證有效性，並能取得遠端伺服器版本供工具比對。資料庫密碼使用作業系統安全存放機制（Windows Credential Manager）加密保護，禁止以明文儲存於組態檔。在 WPF 中提供直覺的連線設定管理介面。

**Blocked by:** 01: 客戶端工具偵測管線與官方安裝指引

**Status:** done

- [x] 連線測試功能可驗證連線狀態並精確讀取遠端伺服器主版本
- [x] 密碼採用 Windows 憑證安全存儲，組態檔僅保存設定識別碼
- [x] WPF 提供連線管理介面與連線測試即時反饋
