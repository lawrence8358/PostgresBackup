已完成。新增 `MachineScopedStore`（路徑與 ACL 規則）、`MachineScopedCredentialStorage`（DPAPI LocalMachine + 額外熵值）、`MachineScopedConnectionProfileRepository`、`IPasswordReader` + `ConsolePasswordReader`、`DirectoryAccessInfo`、`ProfileCommand`。存放檔名為 `cli-connection-profiles.json` / `cli-credentials.dat`，憑證 key 前綴亦分開（`PostgresBackup:Cli:Profile:`）。`IEnvironmentProbe.GetDirectoryAccessInfo` 回傳 **SID 字串**，使權限判斷不受 OS 語系影響。

**後續票 06 完成後，此票的「存放區建立時即套用限制性檔案權限」一條被發現有實作缺口並已修正** —— 原本只在自行建立目錄時套用，既有目錄直接略過，導致低權限使用者可搶先建立 `C:\ProgramData\PostgresBackup` 使其保留寬鬆繼承權限。詳見 `.scratch/secure-scheduled-credentials/issues/11-store-directory-preemption.md`。

CLI 測試專案新增 `[assembly: CollectionBehavior(DisableTestParallelization = true)]`，因 `Console.SetOut` 為行程層級共用狀態，平行執行會互相奪走擷取中的輸出。
