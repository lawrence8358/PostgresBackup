**Blocked by:** None (can start immediately).

**Status:** resolved

- [x] 側邊導覽不再顯示全域系統日誌。
- [x] 全域日誌檢視、狀態、依賴註冊與備份／還原雙重寫入均移除。
- [x] 備份及還原頁仍各自顯示完整即時終端輸出。
- [x] 導覽初始目的地為設定頁，且所有保留目的地均可由純狀態或路由接縫測試。
