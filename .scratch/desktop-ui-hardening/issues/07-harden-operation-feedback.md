# 07: 限制作業錯誤詳情並批次更新終端輸出

**What to build:** 讓備份與還原作業在大量工具輸出或長錯誤訊息下仍保持可操作；狀態摘要不得遮蔽頁面，完整詳情必須可捲動及複製，終端輸出須批次送往 UI。

**Blocked by:** 03 讓設定、備份與還原頁自適應可用空間。

**Status:** resolved

- [x] 備份與還原失敗時顯示簡短狀態摘要，完整錯誤位於高度受限的獨立區塊。
- [x] 錯誤詳情支援垂直與水平捲動、文字選取及一鍵複製。
- [x] 備份與還原共用批次終端輸出機制，不再對每一行同步呼叫 UI Dispatcher 或重綁完整文字。
- [x] 長時間作業仍提供近即時輸出，作業結束前會強制刷新所有待處理內容。
- [x] 自動化測試以大量輸出重現並限制 `TerminalOutput` 通知次數，同時驗證輸出不遺失；測試不建立或顯示 WPF 應用程式。

## Comments

- Red：備份與還原各同步輸入 1,000 行時，原實作均產生 1,001 次 `TerminalOutput` 變更通知。
- Green：共用緩衝器以約 225 ms 為批次刷新，測試觀察到 1–2 次通知，且 `line-0000` 至 `line-0999` 均保留；作業結束前強制刷新。
- 失敗結果與未預期例外在兩個 ViewModel 均以自動化測試覆蓋，完整詳情可透過注入式剪貼簿邊界複製。
