# 03: 讓設定、備份與還原頁自適應可用空間

**What to build:** 讓設定、備份與還原頁在大型視窗有效使用內容區，並讓備份與還原終端填滿剩餘高度，同時維持小型視窗可操作性。

**Blocked by:** None (can start immediately).

**Status:** resolved

- [x] 三個頁面不再被固定最大寬度限制，卡片會在既有邊距內伸展。
- [x] 寬螢幕表單仍維持清楚的欄位分組，不會形成難以閱讀的超長單欄。
- [x] 備份與還原終端會吸收設定區下方的剩餘高度，並在超高視窗停止於 420 DIP，避免日誌壓倒主要表單。
- [x] 視窗高度不足時仍可捲動至所有控制項，終端亦保有可用的最小高度。
- [x] 終端清除、複製與自動捲到底部等既有互動維持不變。
