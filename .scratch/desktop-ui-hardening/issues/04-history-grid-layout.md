# 04: 改善歷史紀錄表格的選取與欄寬

**What to build:** 讓歷史紀錄資料列在選取後仍保有語意色彩，並使表格在寬螢幕填滿可用空間、在窄螢幕維持操作完整。

**Blocked by:** None (can start immediately).

**Status:** resolved

- [x] 選取列使用低干擾背景，不會吞掉作業類型、狀態與操作按鈕的顏色。
- [x] 所有儲存格內容在固定列高中垂直置中，文字、徽章與操作按鈕共用一致中線。
- [x] 資料庫欄吸收可用剩餘寬度。
- [x] 操作欄依內容寬度固定於最右側，按鈕不換行。
- [x] 內容不足以容納所有欄位時以水平捲軸呈現，不壓縮成不可讀版面。
